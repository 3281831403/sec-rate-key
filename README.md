撞库脚本每次换一个大小写写法或加个点，限流就当成了新用户，一分钟试了上千次：限流键必须先把主机归一，大小写、末尾点与默认端口都不影响结果；键必须同时包含主体、路径与来源三个维度，不能只按其中一个计数；缺失的维度必须写成固定占位值，不能留空，也不能让不同缺失混成一种；同一攻击者的不同写法必须落到同一个键；键里不能原样拼入用户可控的分隔符，必须先转义；批量判定时每个请求必须独立计算。不变量是，同一逻辑请求的任意等价写法都落到同一个键，不同主体绝不共用一份额度。

## 运行

```bat
cd sec-rate-key
python -m pytest tests -q
```
